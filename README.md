# TiendaSonidoVivo (Desarrollo Fullstack II)
Nombre del Proyecto: Tienda Sonido Vivo

Tipo de Proyecto: E-Commerce

Integrantes: Ignacio Espinoza, Axel Juris

Lenguajes: HTML5, JavaScript, CSS

Descripción de negocio del proyecto:

# Descripción del código del proyecto:

Empresa: Sonido Vivo, tienda de instrumentos musicales, equipos de sonido y accesorios ubicada en Viña del Mar (11 años de trayectoria).

Equipo: Atendida por su dueño y dos vendedores.

Oferta: Catálogo de 340 referencias de productos y servicio de reparación de instrumentos de cuerda.

Situación actual: Las ventas son principalmente presenciales, pero el reciente aumento de pedidos online (WhatsApp e Instagram) desde otras ciudades ha generado una sobrecarga operativa que el equipo actual no logra manejar.

# Páginas: 5 (+ 1 Adicional):

Todas las páginas deben formar parte de un mismo sitio web. No deben desarrollarse como páginas independientes.

Navegación:

El usuario debe poder desplazarse entre las diferentes secciones mediante enlaces o botones.

La navegación debe ser coherente y funcional.

Diseño:

Todas las páginas deben mantener una identidad visual común:

Misma familia de colores.
Tipografías coherentes.
Menú de navegación consistente.
Distribución ordenada de los contenidos.
Diseño legible y comprensible.


Recursos multimedia

El sitio deberá incorporar recursos como:

  - Imágenes.

  - Video.

  - Botones.

  - Enlaces.

  - Formularios.


# 1. Página principal — index.html

La página principal será la presentación de la tienda.

Debe incluir:


Una estructura desarrollada utilizando HTML5 semántico.

Encabezado (header) con el nombre o logotipo de la tienda.

Menú de navegación (nav) que permita acceder a las distintas páginas.

Una sección de presentación de la tienda.

Texto descriptivo relacionado con el negocio.

Imágenes relacionadas con los productos o la tienda.

Al menos un video incorporado a la página.

Enlaces o botones que permitan al usuario dirigirse al catálogo.

Pie de página (footer).

Uso de una hoja de estilos CSS externa.


La página debe funcionar como el punto de entrada al sitio y permitir al usuario desplazarse fácilmente hacia las demás secciones.



# 2. Página de productos — productos.html

Esta página corresponderá al catálogo de productos disponibles en la tienda.

Debe incluir:


Título y descripción de la sección.

Múltiples productos presentados de manera organizada.

Una imagen para cada producto.

Nombre del producto.

Descripción breve.

Precio.

Botones o enlaces asociados a los productos.

Navegación hacia las demás páginas del sitio.

Aplicación de estilos mediante CSS externo.


Los productos deben estar organizados de forma clara, permitiendo que el usuario pueda identificar fácilmente la información de cada uno.

Los botones pueden utilizarse, por ejemplo, para ver detalles, seleccionar un producto o realizar una acción relacionada con la compra.

# 3. Página de detalle de producto — producto.html

Esta página estará destinada a mostrar información más detallada de un producto seleccionado.

Debe incluir:


Nombre del producto.

Imagen o imágenes del producto.

Descripción detallada.

Precio.

Información adicional del producto.

Botón o elemento interactivo.

Navegación para regresar al catálogo o acceder a otras páginas.

Aplicación de CSS externo.

Al menos una interacción utilizando JavaScript.


La interacción debe producir algún comportamiento observable para el usuario.


Por ejemplo:

Mostrar u ocultar información.
Modificar dinámicamente un elemento.
Seleccionar una cantidad.
Calcular un valor.
Mostrar un mensaje.
Cambiar información presentada en la página.

# 4. Página de inicio de sesión — login.html

Esta página deberá permitir representar el acceso de un usuario al sistema. Debe contener un formulario HTML con, al menos:


Campo para correo electrónico o nombre de usuario.

Campo para contraseña.

Botón para enviar el formulario.

Enlace hacia la página de registro.

Enlace para regresar a la página principal.

Diseño coherente con el resto del sitio.

El formulario deberá incorporar validaciones mediante JavaScript.


Por ejemplo, se deberá comprobar que:

Los campos obligatorios no estén vacíos.
El correo electrónico tenga un formato válido.
La contraseña cumpla las condiciones establecidas por el equipo.
Se entregue un mensaje apropiado cuando exista un error.


Las validaciones deberán realizarse mediante JavaScript y no limitarse únicamente al atributo required de HTML

# 5. Página de registro — registro.html


Esta página permitirá representar el registro de un nuevo usuario.
Debe contener un formulario con diferentes tipos de campos.

Por ejemplo:


Nombre.

Apellido.

Correo electrónico.

Contraseña.

Confirmación de contraseña.

Fecha de nacimiento.

Otros datos que el equipo considere pertinentes para el contexto de la tienda.

Botón para registrar.

Enlace hacia la página de inicio de sesión.

Enlace hacia la página principal.


El formulario deberá incorporar validaciones mediante JavaScript.



Como mínimo, deberá considerar:

Validación de campos obligatorios.
Validación del formato del correo electrónico.
Validación de los campos que deban contener solamente letras.
Validación de campos numéricos cuando corresponda.
Comprobación de que las contraseñas coincidan.
Mensajes de error comprensibles para el usuario.
Las expresiones regulares podrán utilizarse cuando sean apropiadas para validar los datos ingresados.

# 6. Página de Compra — compra.html

Sin requisitos solicitados.


Página de compra con un formulario de datos validados.
Se accede desde el detalle de un producto.
